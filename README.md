# Watermelon

Watermelon combines a Telegram userbot (Telethon, running as your Telegram account) with the existing Telegram bot (aiogram). It stores incoming text messages and can analyze messages with the configured Gemini-compatible API.

## Privacy and security

- Never publish `TG_SESSION`, `TG_API_HASH`, `LLM_API_KEY`, or `BOT_TOKEN`. The session string grants access to your Telegram account.
- Create the userbot session on your own computer and add it to Render only through **Environment**.
- The userbot stores incoming text messages after startup; it does not automatically import every chat's complete history.
- `.analyze USER_ID` can analyze accessible history in the current chat.
- `.analyzeall USER_ID` analyzes messages saved from different chats after startup.
- Process or send messages to an LLM only when you have permission to do so.

## 1. Telegram API credentials and session

1. Open https://my.telegram.org and sign in.
2. Open **API development tools** and get `api_id` and `api_hash`.
3. Install Python 3.12+ and dependencies locally, then create a session:

```bash
pip install -r requirements.txt
python -m app.create_session
```

Keep the generated session string private.

## 2. Render Web Service

Create or open a **Web Service** connected to this repository.

**Build Command**
```bash
pip install -r requirements.txt
```

**Start Command**
```bash
python -m app.web
```

The `app.web` entry point binds an HTTP health endpoint to `0.0.0.0:$PORT` for Render and runs both the existing bot and userbot concurrently.

## 3. Environment variables

Add these under Render → **Environment**:

- `BOT_TOKEN` — token for the existing BotFather bot (you add this yourself).
- `TG_API_ID` — API ID from my.telegram.org.
- `TG_API_HASH` — API hash from my.telegram.org.
- `TG_SESSION` — session string generated by `python -m app.create_session`.
- `LLM_BASE_URL` — `https://generativelanguage.googleapis.com/v1beta/openai/`.
- `LLM_API_KEY` — API key for the configured Gemini-compatible endpoint.
- `LLM_MODEL` — defaults to `gemini-2.5-flash`.
- `DATABASE_PATH` — defaults to `messages.db`.
- `MAX_MESSAGES_PER_ANALYSIS` — defaults to `100`.

The combined Web Service requires both the bot token and the userbot credentials. The userbot by itself does not require `BOT_TOKEN`, but the existing bot component does.

## 4. Userbot commands

Send these from your own Telegram account:

- `.helpwatermelon` — show help.
- `.analyze USER_ID` — analyze accessible history for a user in the current chat.
- `.analyze` — in a private chat, analyze the conversation partner.
- `.analyzeall USER_ID` — analyze saved messages for a user across chats.

## 5. Health check and storage

- Health endpoint: `/health`, which returns JSON while the process is running.
- Render's local filesystem may not persist across service replacement or redeployment. For durable SQLite storage, configure a persistent disk or move to an external database.
- Model output can be inaccurate and should not be treated as a diagnosis or definitive judgment about a person.

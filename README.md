# Telegram User Profiler

Telegram-бот для анализа сообщений участника чата и выдачи структурированного JSON-профиля.

## MVP

- Команда `/analyze <user_id>` анализирует только сообщения, которые бот уже получил в доступном ему чате и которые сохранены в локальной SQLite.
- Бот не может задним числом читать историю чата, к которой Telegram Bot API не предоставил доступ.
- Результат возвращается в фиксированном JSON-формате.
- Не делайте выводы о чувствительных личных характеристиках. Профиль описывает только наблюдаемое поведение и явно заявленные пользователем сведения.
- Используйте анализ только в чатах, где у вас есть право обрабатывать сообщения, и уведомите участников о назначении бота.

## Стек

- Python 3.12+
- aiogram 3 — Telegram Bot API
- SQLite — MVP-хранилище сообщений
- OpenAI-compatible API — анализ текста (например, OpenRouter или другой провайдер)

## Запуск

1. Установите Python 3.12+.
2. Создайте бота через `@BotFather` и получите токен.
3. Скопируйте `.env.example` в `.env` и заполните переменные.
4. Установите зависимости:

   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

5. Запустите:

   ```bash
   python -m app.main
   ```

## Использование

- `/start` — описание.
- `/analyze <user_id>` — анализ собранных сообщений пользователя в текущем чате.
- Бот сохраняет обычные текстовые сообщения, которые Telegram доставляет ему. В BotFather настройте privacy mode осознанно; для групповых сообщений боту может понадобиться отключить privacy mode или назначить его администратором.

## Ограничения

- Анализ личности по переписке является предположительным. `who_is_he` должен отмечать, когда профессия/грейд не подтверждены словами пользователя.
- `toxicity_score` — эвристическая оценка языка в доступных сообщениях, не психологический диагноз.
- `is_needed` зависит от ваших целей; в MVP модель должна объяснять неопределённость, а не объявлять человека объективно «нужным/ненужным».
- Не загружайте в стороннюю LLM личные или конфиденциальные сообщения без правового основания и информирования участников.

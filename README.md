# Watermelon Userbot

Личный Telegram userbot на Telethon: работает через ваш Telegram-аккаунт, собирает новые входящие текстовые сообщения из чатов, к которым у аккаунта есть доступ, и анализирует сообщения через Gemini API.

## Важно о безопасности и приватности

- Не публикуйте `TG_SESSION`, `TG_API_HASH` или `LLM_API_KEY`. Строка сессии позволяет получить доступ к аккаунту.
- Создавайте сессию на собственном компьютере и добавляйте её в Render только через Environment.
- Userbot обрабатывает новые входящие текстовые сообщения после запуска; он не загружает всю историю каждого чата в базу автоматически.
- Команда `.analyze USER_ID` может анализировать доступную историю текущего чата через Telegram API.
- Команда `.analyzeall USER_ID` анализирует только сообщения из разных чатов, сохранённые после запуска.
- Отправляйте сообщения в Gemini только если у вас есть право обрабатывать эти данные. Не используйте вывод как психологический диагноз или как достоверный вывод о чувствительных характеристиках человека.

## 1. Telegram API credentials

1. Откройте https://my.telegram.org и войдите в свой аккаунт.
2. Перейдите в **API development tools** и получите `api_id` и `api_hash`.

Токен BotFather для userbot не нужен.

## 2. Создание сессии на своём компьютере

Установите Python 3.12+ и клонируйте репозиторий. В терминале в папке проекта:

```bash
pip install -r requirements.txt
python -m app.create_session
```

Скрипт запросит `TG_API_ID`, `TG_API_HASH`, номер телефона, код Telegram и, если включена, пароль двухэтапной аутентификации. В конце он выведет строку сессии. Скопируйте её сразу в безопасное место; никому её не отправляйте.

## 3. Render

Создайте или откройте сервис типа **Background Worker**.

**Build Command**
```bash
pip install -r requirements.txt
```

**Start Command**
```bash
python -m app.userbot
```

В **Environment** добавьте переменные:

- `TG_API_ID` — числовой API ID с my.telegram.org
- `TG_API_HASH` — API hash с my.telegram.org
- `TG_SESSION` — строка, созданная командой `python -m app.create_session`
- `LLM_BASE_URL` — `https://generativelanguage.googleapis.com/v1beta/openai/`
- `LLM_API_KEY` — ключ Gemini API из Google AI Studio
- `LLM_MODEL` — `gemini-2.5-flash`
- `DATABASE_PATH` — `messages.db`
- `MAX_MESSAGES_PER_ANALYSIS` — `100`

Для текущего userbot не нужны `BOT_TOKEN` или отдельный бот BotFather.

## 4. Команды

Отправляйте команды от своего аккаунта. Командное сообщение будет удалено userbot-ом после обработки, если Telegram разрешает его удалить.

- `.helpwatermelon` — справка.
- `.analyze USER_ID` — анализ доступной истории указанного пользователя в текущем чате.
- `.analyze` — в личном чате анализ собеседника.
- `.analyzeall USER_ID` — анализ сохранённых новых сообщений пользователя из разных чатов.

Для поиска Telegram ID пользователя можно использовать известный вам ID или получить его из надёжного Telegram ID-инструмента. Не передавайте посторонним доступ к своему аккаунту.

## 5. Ограничения

- Анализ текущего чата использует историю, которую Telegram API разрешает получить аккаунту.
- Глобальный анализ использует только сообщения, которые userbot успел сохранить после запуска.
- SQLite на файловой системе Render может очищаться при пересоздании сервиса/потере файловой системы. Для долговременного хранения подключите persistent disk или внешнюю базу.
- Модель может ошибаться; `toxicity_score` — приблизительная оценка языка в конкретных сообщениях.
